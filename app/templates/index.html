BAM → VCF variant caller

Upload a coordinate-sorted, aligned BAM file and this will run GATK4 HaplotypeCaller against the bundled small reference genome, hard-filter the resulting variants, and return a downloadable VCF plus a summary of what was found.



No BAM handy? The pipeline's own output is a good test file: results/align/NA_tiny.recal.bam from the Snakemake run in the parent directory.
